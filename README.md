# pimplepoppers.be

One-page site for Pimple Poppers, served by GitHub Pages.

- `template.html` — the source. Edit this.
- `build.py` — run `python build.py` to regenerate `index.html` (and the artifact build).
- `index.html` — generated. Do not edit by hand.

The support-desk URL appears once, as `DESK` at the top of `build.py`.
